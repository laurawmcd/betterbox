# Values card-sorting exercise

The Values suit holds ethical principles and commitments. Sorting them together shows which the group holds, which they disagree about, and how far the project lives up to them.

## How to run it

1. As a group, sort the Values cards: prioritize, cluster and discard.
2. Add your organization's own values and principles on the blank cards.
3. Layer in cards from other suits, such as Accessibility, that speak to your priorities.
4. Ask how your project lives up to the values the group has chosen, and where it falls short.

## Tips

- Ask people to explain a discard as well as a choice. Disagreements about what to drop are often where the useful conversation is.
