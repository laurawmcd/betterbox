# Installability

Installability is the ease of installing the system on all the necessary platforms. It matters whether end users install it themselves or a technical team deploys it, since that decides what you can ask of users' devices, storage, skills and connectivity.

## Questions to ask

- Who installs it: users or a technical team?
- Which devices and operating systems must it run on?
- What does installation require in bandwidth, storage and skills?
- How are updates delivered?

## In a workshop

Write down the steps a new user takes from receiving the link to completing a first task, and count them.
