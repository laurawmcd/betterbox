# Licensing and copyright

Check whether the client requires particular rights to use the application or ownership of the code, and whether those requirements restrict which software libraries you can use. Licences on open source components, content and data all carry conditions, and it is far easier to find out early.

## Questions to ask

- Who will own the code, the content and the data?
- Does the client require particular rights?
- Do those requirements rule out any libraries or tools?
- Which licences apply to the components we already use?

## In a workshop

Ask the developer for a list of the main components and their licences. If none exists, that is the first action.
